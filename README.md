# Vortex Mandala using Python Turtle

## Overview

This project creates a colorful **Vortex Mandala** pattern using Python's built-in **Turtle Graphics** library. It combines geometric star shapes, trigonometric calculations, and HSV color gradients to generate an artistic spiral design.

## Features

* 🎨 Smooth rainbow color transitions using the HSV color model.
* ⭐ Repeating five-point star patterns.
* 🌀 Spiral (vortex) arrangement of shapes.
* 📐 Uses mathematical functions for positioning and animation.
* 🐢 Built with Python Turtle Graphics.

## Technologies Used

* Python 3
* Turtle Graphics
* `math` module
* `colorsys` module

## How It Works

1. Creates a Turtle graphics window with a black background.
2. Iterates through multiple drawing positions.
3. Calculates each shape's angle and distance from the center using mathematical formulas.
4. Assigns a unique color based on the HSV color spectrum.
5. Draws a five-point star at each position.
6. Repeats the process to form a colorful vortex mandala.

## Customization

You can experiment with the artwork by changing:

* `iterations` – controls the number of stars drawn.
* `cycles` – changes the spiral pattern.
* `distance` – adjusts spacing between shapes.
* `pensize` – changes line thickness.
* HSV color values – creates different color themes.
